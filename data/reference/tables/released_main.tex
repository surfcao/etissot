We apply radius refinement to 50 selected checkpoint--site cases across seven checkpoints, covering ordinary anisotropy, high anisotropy, initial fallback and near-antimeridian locations. Starting radii are reduced where needed to keep the disc within a chart. The criterion accepts 34 cases and rejects 16. All eight CSP-iNat cases fail; GeoCLIP, SatCLIP-L40 and CSP-fMoW also have failures. Among accepted cases with automatic derivatives, maximum anisotropy error is 0.141\%, maximum minor-eigenvalue-relative tensor error is 0.780\%, and maximum shape discrepancy is $D=1.001411$. The 0.5\% successive-change threshold is therefore a stopping rule, not an accuracy guarantee. Supplementary \S S5 reports site selection, radii, errors and precision.

Boundary checks cover all thirteen checkpoints. GeoCLIP, CSP and Climplicit retain jumps across the antimeridian. SINR is longitude-periodic but gives different outputs for coordinate-equivalent poles. SatCLIP passes the sampled equivalence checks. We record these boundary properties separately from local stretching; passing a finite set of tests does not establish global smoothness.
