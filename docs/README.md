# Documentation

- `api.md`: public functions, the encoder adapter and checkpoint acquisition.
- `data.md`: cached study inputs and their provenance.
- `models.md`: the thirteen released checkpoints, their sources and licenses.
- `reproducibility.md`: commands to reproduce the study from the cached data.
- `testing.md`: running the test suite.
- `validation/`: release validation records.
- `provenance.json`, `file_migration.json`: file provenance and old-to-new filename mapping.

Start with the repository README for installation and quick start.
